Files:
- index.html
- styles.css
- script.js

How to publish on GitHub Pages:
1. Create/open your GitHub repository.
2. Upload all three files to the main/root folder.
3. Open Settings > Pages.
4. Choose Deploy from a branch.
5. Select your main branch and / (root).
6. Save and wait for GitHub Pages to publish.

IMPORTANT:
This is a front-end demo. The booking form does not send real orders to a database.
Before accepting real customers, connect the form to a secure backend/database and add proper provider verification, privacy terms, service-area rules and payment handling.
